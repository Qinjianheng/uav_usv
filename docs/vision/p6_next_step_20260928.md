# P6 启动：现有 P5 数据的误差分层与下一步

日期：2026-09-28。基线：`40dda14811fb249f7a637360abe238934e000b0c`。本轮仅复核已有数据和代码，未启动仿真、修改在线算法或重算复杂反事实。

## 当前已知

在线 `RgbDepthPairBuffer` 在有界队列中按原始采集时间差最小配对，每帧最多使用一次，允许差值上限 `maximum_rgb_depth_skew=0.1 s`。当前链路是 **mask(t_rgb) + depth(t_depth) + PX4 位置/姿态(t_rgb)**：`measurement_stamp` 取映射后的 RGB 时间，PX4 历史位姿按该时间查询。这是允许非零 skew 的配对机制，不是已证实的代码错误。

| 最新 `left_mad_recheck`，整段有效帧相机系 RMSE | **0.0746 m**（248 帧） |

三级分层：L1 是上述物理相机系球心误差；L2 是使用 Gazebo 精确 UAV 位姿、保持同帧相机观测与外参的目标 NED 误差，**现有最终汇总没有可直接引用的 L2 指标，需要 P6 专门计算**；L3 是实际 PX4 位姿下的在线 NED 误差。最新左离轴 L1 约 0.075 m、L3 约 0.685 m，误差增长主要发生在相机到世界/NED 的位姿变换阶段，不能归咎于像素检测。两层样本口径均为整段 248 个有效帧；保存 ROI 的 17 帧不能代替整段指标。

40–60 ms 子集的实际 skew P50/P95/max 为 +Y 48/52/52 ms、−Y 52/52/52 ms。其理论位移尾部与动态 B 相机系误差同量级，说明 skew **可能是重要贡献**；这是保持 RGB 射线、分别使用两个采样时刻的真值几何得到的反事实量，不是独立实验测出的因果改善量，不能直接从 RMSE 中相减，也不能声称已解释全部动态误差。0.1 s 配对上限对应的尾部仍需单独考虑。

历史 KF 基线：+Y 原始测量/KF RMSE 为 1.136/1.169 m，KF source age P50/P95 为 0.265/0.382 s；−Y 为 0.736/0.889 m，source age 为 0.192/0.390 s。**历史 P5 数据没有证据表明 KF 能消除当前系统偏差。**该基线主要来自旧 A 球心前端，且原始测量与 KF 采样数不同，不能作为当前 B 前端的最终 KF 结论；此时不调 Q/R。

## 尚未知道与优先级

尚未独立测得同步误差的因果贡献；尚未分开 PX4 位置与姿态对 L3 的贡献，也没有 L2 统一指标；尚未得到新 B 前端下的动态转弯 KF 基线。按现有证据排序：**1. RGB/Depth 单因素同步实验；2. PX4 位姿贡献分层；3. 新 B 前端转弯 KF 基线。** 理论 skew 位移与动态相机系误差同量级，而 PX4 位姿贡献尚无同口径 L2/L3 分解，当前不足以交换前两项。

## 下一步只做三个实验

1. **UAV 静止、USV 横移。**目的：单独辨识目标运动造成的 RGB/Depth 错位。记录 RGB/depth raw 和 mapped 时间、触发式小 ROI 掩膜与深度、内参、两个时刻的 UAV/USV Gazebo 位姿、PX4 位姿、原始 B 观测与有效率。判断：在 +/− 横移中，理论错位应能预测相机系残差的方向和量级；只在同等有效率及相同帧口径下，比较更严格配对或同时间样本的误差，不能仅凭相关性改在线同步。
2. **USV 静止、UAV 横移。**目的：区分载机运动 skew 与 PX4 位置/姿态误差。记录上述双时间戳和 ROI、Gazebo UAV 完整位姿、PX4 同时刻位置与四元数、USV 实体位置及在线观测。用定位器实际变换在同帧离线计算 PX4/PX4、Gazebo/Gazebo、Gazebo 位置+PX4 姿态、PX4 位置+Gazebo 姿态四组，得到 L1/L2/L3。判断：比较正反向的有符号误差、RMSE/P95 与有效帧数，确认主要增长层和位置/姿态贡献后才考虑对应修复。
3. **新 B 前端下的目标转弯 KF。**目的：在前端和位姿误差分层后，量化滤波降噪与转弯滞后。记录清洗后的 `TargetObservation`、KF 状态与时间、目标真值、innovation/covariance、拒绝原因、有效观测间隔及 source age。判断：分别在匀速与转弯阶段比较原始测量/KF 的位置 RMSE/P95、速度误差和时间滞后；只有重复证据支持时再讨论 Q/R。

上述实验均保持视觉 shadow-only、规划控制使用仿真真值；Gazebo 真值只用于离线评价，不进入在线视觉/KF。数据依据：`data/experiments/current/p5_20260927/p5_roi_analysis_final.json`、`left_mad_recheck_roi_analysis_v2.json`、`left_mad_recheck/vision_p5_capture_20260928_085955_904648.csv`、`p5_kf_baseline_final.json`、`plus_y_groundtruth_timing.json`、`minus_y_groundtruth_timing.json`，及 `docs/vision/vision_rgbd_geometry_timing_kf_p5_20260927.md`。
