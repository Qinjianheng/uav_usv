# P5：RGB-D 球心几何、采样时间与 KF 基线（2026-09-27，9月28日收尾）

## 先回答七件事

1. **查明的原因**：P4 的 `DEPTH_MAD_HIGH` 无效消息遗漏 bbox、内参与球心中间量，使旧异常 ROI 错存为左上角 9×9；新实测异常帧中约 66% 的红掩膜射线在 depth 采样时已不穿过实体球，穿过球的深度点则全部在真实球面 0.1 m 内，支持时间错位时背景深度混入。常态球心 `median(X depth)+radius` 仍是几何近似，和 MAD 离群拒绝属于不同问题。
2. **在线修改**：`target_geometry_from_rgbd` 仅将半径沿代表观察射线加到相机 X 深度表面点；`publish_invalid_observation` 仅补齐拒绝观测的评估几何字段。后者保持 `valid=false`、零置信度、NaN 位置/协方差，也不发布有效目标位置。没有改 KF、控制、相机外参或时间补偿。
3. **球心结果**：六个已采真实 ROI 场景中，B 相对历史 A 的相机系 RMSE、P95、最大误差均未退化，有效率同为 100%（以保存的完整有效 ROI 为分母）。短 shadow-only 复验同帧 17 个 ROI 为 **0.099→0.070 m**；这不是六场景整段在线 RMSE。C/D 拟合有退化与失败，未上线。
4. **RGB/Depth skew**：静态目标且载机稳定时虽可有约 48–52 ms raw stamp 差，几何位移中位数为 0；±Y 中固定 RGB 掩膜、只把理想球面深度从 RGB 时刻换到 depth 时刻，三维理论位移在常见 40–60 ms 子集中 P95 分别约 **0.198/0.235 m**。两方向的有符号 X 位移没有稳定反号，故不据此重写同步或加固定补偿。
5. **Gazebo→PX4 groundtruth**：用动态模型位置精确匹配 pose/info 与 ULog，+Y 2279、−Y 2160 个唯一样本的 `groundtruth timestamp_sample − pose header sim stamp` P50/P95 都为 **0 s**，`timestamp−timestamp_sample` 也为 0。P4 怀疑的几十毫秒固定**仿真采样**延迟未获支持；PX4 桥接的墙钟回调接收时刻仍未直接记录。
6. **KF**：原始视觉与 KF 的 NED 米级 signed bias 基本同向；+Y 独立统计的 RMSE 1.136/1.169 m，−Y 为 0.736/0.889 m（采样频率不同，不作逐帧因果差值）。当前主要系统偏差在 KF 之前，尚无调 Q/R 的依据。动态 KF source age P50 为 0.265/0.192 s，需后续专门测试跟踪滞后。
7. **未解决**：同步误差在具体帧中与相机运动、球面近似、PX4 位姿误差的份额仍需更专门的独立运动实验；桥接墙钟回调时延不可由本轮 ULog 单独辨识；转弯阶段 KF 尚无可靠基线。本轮未将视觉接入闭环。

## 异常 ROI 与深度分布

旧 P5 原始采集中 static5/left/right 有 4/7/3 条 MAD-high 保存 ROI；因旧无效消息 bbox=[0,0,0,0] 且 fx/fy=0，这 14 个 9×9 文件在最终 JSON 明确标记为不可用，不用于球面异常成因判断。修改后只补做一次 36 s left shadow-only 观察，触发 2 条 MAD-high：bbox `[320,228,337,242]` 与 `[312,262,330,277]`，ROI 尺寸分别 34×31、35×32，红色像素 215/241，fx=fy=269.968；掩膜和 depth ROI 形状一致，拒绝 MAD 为 0.606/0.517 m，均非左上角。两帧红掩膜中只有 34.4%/34.0% 的射线在 depth 时刻穿过实体球；穿过球的测量点均落在真实球面 0.1 m 内，而正常 ROI 的中位球面射线覆盖率 97.5%。因此本次异常的宽深度分布有真实背景混入证据，RGB/Depth 不同时刻的投影错位是有力解释；仍未把所有 MAD-high 帧推广为同一原因。MAD 门控解决离群拒绝，不修正正常帧的球心近似。

采集器只缓存有限图像帧并触发保存 bbox 周围小 ROI，不录长期视频；拒绝零 bbox/零内参。`roi_pair_missing` 在新复验为 11，说明独立评估订阅仍可能漏配，缺失者未纳入 ROI 性能统计；不影响在线配对器。
