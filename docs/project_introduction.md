# UAV-USV非合作目标截击仿真项目简介

## 项目目标

本项目面向多旋翼无人机（UAV）追踪和截击非合作无人艇（USV）的研究，构建了基于ROS 2 Humble、PX4 SITL和Gazebo的仿真实验平台。当前重点是验证目标机动预测、有限时域截击轨迹规划、动力学约束和末端接近策略，并为后续接入真实视觉、ToF或激光雷达感知闭环保留统一接口。

工作空间位于 `/home/qin/data/uav_usv`，PX4源码默认位于 `/home/qin/Projects/PX4-Autopilot`。

## 当前仿真流程

一次完整实验包含以下阶段：

1. 启动Gazebo海面世界、PX4 SITL、Micro XRCE-DDS Agent和ROS 2节点；
2. PX4在地面进入Offboard保持状态，但暂不解锁；
3. 输入 `X` 并回车，无人机解锁起飞，USV同时开始运动；
4. 无人机爬升至巡航高度并进入 `FOLLOW` 跟随模式；
5. 输入 `Y` 并回车，进入预测截击模式；
6. 系统根据三维捕获距离、海面接触、状态有效性和动力学约束给出实验结果。

命令台还支持输入 `R` 并回车，完整停止本轮Gazebo、PX4、DDS和ROS实验进程，然后跳过编译自动开始一轮新仿真；输入 `Q` 只退出命令台，不关闭已经启动的实验终端。

## 当前数据与控制链路

```text
USV仿真真值 (/target/*)
        │
        ├──> 有界自适应CTRA目标预测
        │         └──> 有限时域截击点与目标曲线
        │                    └──> 三段MINCO轨迹规划
        │                              └──> 速度/位置反馈控制
        │                                        └──> PX4 Offboard
        │
        └──> 成功判定、最小距离和预测误差评价

前视/下视RGB-D相机
        └──> 红色目标分割与深度定位
                  └──> 恒速度卡尔曼滤波
                            └──> 影子评估（暂不控制无人机）
```

当前截击控制仍使用 `/target/position` 和 `/target/velocity` 仿真真值。相机定位与卡尔曼滤波只用于影子评估，不影响控制指令；真值同时用于成功判定和误差评价。

## 核心方法

- **目标运动**：USV以默认4 m/s沿带速度、转率和横向加速度限制的8字轨迹运动，并使用ROS实测时间推进。
- **目标预测**：根据连续速度观测估计转率、转率加速度和纵向加速度，采用有界自适应CTRA进行1–2秒预测；数据不足时退回恒速度模型。
- **跟随控制**：UAV跟踪USV历史航迹上约5米后的参考点，避免转弯时参考点横向突变。
- **截击规划**：进入可达域后使用三段五次MINCO轨迹，同时搜索截击时间、末端闭合速度和目标曲率引导点。
- **几何优化**：参考GCOPTER思想，对中间航点和分段时间进行小规模L-BFGS-B优化，并对速度、加速度和海面净空使用积分罚函数；轨迹返回控制器前仍需通过硬约束复核。
- **末端策略**：远距离保持约5米巡航高度，接近移动捕获点时允许形成约45度飞行轨迹角；该参数不是强制机体俯仰45度。

## 快速启动

首次运行或代码修改后执行：

```bash
cd /home/qin/data/uav_usv
./scripts/uav_lab.sh
```

已经完成构建时可跳过重新编译：

```bash
./scripts/uav_lab.sh --no-build
```

命令台按键为：

- `X`：起飞并启动USV；
- `Y`：进入截击；
- `R`：完整重启仿真；
- `Q`：退出命令台。

更详细的启动、话题与分析命令见项目根目录的 [`README.md`](../README.md)，模块关系见 [`architecture.md`](architecture.md)。

## 实验记录

控制节点将实验过程保存为CSV，默认目录为 `data/experiments/current/`。日志包含：

- UAV状态、USV真值位置速度及相对运动状态；
- 相机定位、卡尔曼状态及0.5、1.0、2.0秒预测误差；
- 截击参考、MINCO分段时间、优化迭代与约束诊断；
- 最小距离、捕获结果、失败原因及实际运动峰值。

## 当前边界

- 当前红色分割只识别Gazebo中的红色目标球，用于验证图像、深度和坐标变换接口，不代表已经解决现实无标记非合作USV识别。
- 感知与卡尔曼滤波尚未进入控制闭环；后续切换时只能替换规划输入，评价真值必须继续独立保留。
- 当前MINCO是面向无障碍海面的轻量实现，不包含完整GCOPTER的多面体安全飞行走廊、推力、姿态和机体角速度约束。
- Gazebo RGB-D属于理想化几何深度，尚未模拟阳光、海面反射、多径和低反射区域造成的真实ToF误差。
- 单次成功或失败只能说明该次工况结果；在完成多初值、多机动模式的批量实验前，不能宣称成功率已经得到验证。

## 后续工作

近期工作重点是进行新版本批量仿真，分别统计目标预测误差、MINCO可行率、规划耗时、最小距离和动力学约束超限；之后再接入适用于无标记USV的检测/分割与多传感器融合，并逐步完成从真值控制到感知闭环控制的迁移。
