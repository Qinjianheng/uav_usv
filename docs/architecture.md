# 项目架构

## 数据链路

```text
相机/深度/激光
      -> perception/TargetObservation
      -> tracking/TargetState
      -> guidance/TrajectoryPoint[]
      -> controllers/速度或加速度指令
      -> PX4 Offboard
```

`/ground_truth/*` 只用于仿真评估。正式闭环控制应使用 `/tracking/target_state`，避免把仿真真值当作感知结果。

## 模块职责

- `perception`：检测、深度、激光测距、坐标变换与观测协方差。
- `tracking`：时间同步、EKF/IMM、目标速度估计和状态有效性。
- `guidance`：截击时间、目标轨迹预测、PN/APN及路径规划。
- `controllers`：PID、MPC和后续安全约束下的强化学习控制器。
- `mission`：INIT、TAKEOFF、FOLLOW、INTERCEPT、COMPLETE状态机。
- `common`：坐标、限幅、时间戳和通用数据结构。

所有控制器最终应实现统一接口：输入无人机状态、目标状态、参考轨迹和时间步，输出控制指令与诊断信息。

当前跟踪基线使用六状态恒速度线性卡尔曼滤波器，订阅前视RGB-D定位器的 `/perception/front/target_position`，不读取目标真值速度。定位器由红色目标掩膜和对齐深度恢复相机三维坐标，再结合 `(0.35, 0, -0.05)` 米安装平移、12度下俯角、PX4姿态与位置变换到本地NED。滤波后的 `[px, py, pz, vx, vy, vz]` 和6×6协方差发布到 `/tracking/target_state`；按配置预测时域外推的位置发布到 `/tracking/predicted_position`。路径规划器应订阅 `TargetState`，并根据自身规划时域使用状态与协方差进行预测。

现阶段滤波器与真值截击控制并行运行，用于先验证估计误差。完成验证前，现有命中判定仍使用真值，不将滤波估计混入评价链路。

当前截击阶段在每个20 Hz控制周期重新规划。规划器由相邻速度方向变化估计目标转向率，使用1–2秒短时协调转弯（CTRV）模型预测8字等曲线运动。远离目标时采用直接水平闭合并保持5米巡航高度；进入相对移动捕获点的45度几何下滑线后，参考高度随剩余水平距离按一比一连续下降，并以48.7度最大目标俯角约束近距离高度，使固定前视相机不过早越过垂直视场下边界。该角度是飞行轨迹角而非机体俯仰角。终端轨迹尚不可行时仍向0.25米捕获邻域制动，不再在3米规划边界把闭合速度降为零。

进入有限时域可达域后，默认使用三段MINCO-T3轨迹。每段为五次多项式，完整满足UAV起点和预测接触点的位置、速度、加速度状态，并在段间保证位置及一至四阶导数连续。内部引导点由单段最小控制基线和USV预测曲率共同构成；若预测曲率造成速度或加速度不可行，规划器逐级降低曲率权重，而不是立即放弃。候选轨迹按上次可行时域热启动，沿全轨迹检查水平/垂直速度、加速度及触海约束；控制器每周期执行轨迹上前视0.15秒的状态。MINCO矩阵映射在节点初始化时预计算，代表性转弯场景的持续滚动规划耗时约3毫秒。单周期重规划失败时继续执行上一条已验证可行轨迹的剩余时域，并在 `trajectory_planner` 中标记为 `MINCO_T3_HOLD`。可行轨迹在3米终端区内激活后锁定下降；旧轨迹耗尽且目标仍在4米内时，以 `TERMINAL_PURSUIT` 直接追逐海面安全约束内的捕获高度，只有目标重新拉开到4米外才恢复普通追逐高度。CSV中的 `trajectory_planner`、`minco_target_curve_weight` 和 `trajectory_plan_feasible` 用于区分新规划、保留轨迹、终端追逐、曲率松弛和普通追逐回退。

这里实现的是适合当前无障碍海面场景的固定节点、固定分段时间MINCO映射及离散时域搜索，不等同于GCOPTER中包含走廊约束和L-BFGS时空联合优化的完整系统。起飞阶段同时执行Z轴位置控制和XY轴跟随速度控制。预测输入暂时仍来自 `/target/*` 真值话题，成功、触海和最小距离继续由实际相对状态判定；切换传感器后只应替换规划输入，不能替换评价真值。

## 观测约束与后续传感器闭环

本节的设计依据为 Gao 等（2024）《Adaptive Tracking and Perching for Quadrotor in Dynamic Scenarios》，后续引入相机、深度相机或激光雷达时必须重新对照该论文的目标状态估计、可见性约束与末端状态同步方法。

按论文式观测约束，期望观测偏航定义为 `psi_e(p,q) = atan2(q_y-p_y, q_x-p_x)`。当前控制器已经在每个周期根据UAV位置 `p` 与USV估计位置 `q` 更新该偏航，并进行 `[-pi, pi)` 连续化和偏航速率限制。该约束现在保证机头朝向目标，后续应扩展为规划代价中的观测距离、视场角和遮挡约束。

USV是非合作目标，因此不能照搬论文中的视觉标记。引入相机与激光雷达时采用以下替代链路：相机目标检测/分割提供方位与类别，激光雷达在相机视锥内关联点云并提供距离，二者经时间同步、外参和TF变换形成带协方差的 `TargetObservation`；CTRV-EKF估计状态并在数据充分时生成CTRA运动原语，数据不足时退回CV。规划器只读取融合后的 `TargetState` 及协方差，并把目标留在共同视场内；Gazebo全局真值仅用于成功判定和误差评估。

偏航约束只规定水平朝向。安装真实/仿真传感器后，还必须根据相机光轴、机体姿态和云台自由度检查俯仰观测角；若使用前视固定相机，则把俯仰/FOV同时加入轨迹可行性约束，不能仅凭偏航满足就认定目标始终可见。

### 双ToF接入阶段

第一轮日志确认前视相机在末端近距离俯视阶段会持续丢失目标，因此当前使用两台固定RGB-D传感器模拟ToF。前视传感器刚性安装在机体系 `(0.35, 0, -0.05)` 米并向下俯视12度，覆盖起飞、跟随和接近；下视传感器安装在 `(0.05, 0, -0.12)` 米且光轴竖直向下，补充末端机腹下方视场。水平FOV均为1.74 rad，图像为640×480、20 Hz，深度有效范围为0.2–25米。FOV和测距范围是当前仿真参数，不应表述为论文原始相机参数。

两台RGB-D传感器分别发布空间对齐的RGB与 `32FC1` 深度图。`ros_gz_image` 独立完成20 Hz图像桥接，避免像素检测拖慢显示；两个监视器各自以10 Hz对红色目标球做像素掩膜、深度比例和中值距离分析。监视器还根据PX4姿态与目标真值计算水平/垂直观测角及理论视场状态，并发布相邻分析帧变化量。本轮将 `allow_down_fallback=false`，聚合诊断只使用前视，以验证连续前进/下降能否实现单前视覆盖；下视传感器及 `/perception/down/*` 仍持续运行。需要恢复双相机备份时把该参数改为 `true`，选择器才会按“前视丢失3帧切下视、前视恢复10帧切回”的迟滞规则工作。这些真值诊断不得进入后续感知控制闭环。前视ToF位置现在进入卡尔曼滤波影子链路，但不会改变截击控制输入；真值仍负责当前控制基准、成功判定和误差评价。CSV记录相机/KF当前误差，并把制导模型与KF在0.5、1.0、2.0秒前生成的预测和到期真值配对。

Gazebo的RGB-D深度是理想化几何量，不包含真实ToF的太阳红外干扰、水面镜面反射、多径或低反射深度空洞。后续实机迁移必须根据传感器置信度过滤无效深度，并重新标定有效距离与协方差。

固定前视相机的主要风险发生在水平距离很小而UAV仍高于USV时：目标俯视角会越过约41.6度的垂直半视场。下视ToF用于覆盖这一区域；后续应从完整航迹日志验证两者是否存在视场空隙，并在接入真实检测器后把选择依据扩展为检测置信度、深度置信度和时间同步质量。

感知闭环分三步迁移：

1. 已完成：`/target/*` 真值负责控制、预测和评价，相机仅旁路验证可见性；
2. 当前影子验证：相机检测生成观测与估计轨迹，与真值误差及多时域预测误差并行记录，但控制仍使用真值；
3. 正式闭环：规划器改读融合后的 `TargetState`，真值仅用于误差和截击结果评价。

正式闭环还需把论文的观测距离（OD）、观测角（OA）和遮挡效应（OE）写入轨迹代价/可行性约束。当前红色像素计数只能确认目标在画面中，尚不能证明目标位于理想成像区域，也不能处理海浪、机体遮挡或无标记USV识别。

## 截击结果判定

截击从Y命令被接受时开始计时。真值相对轨迹在相邻控制周期之间连续进入半径为0.25米的三维捕获球时，判定为成功；不能只检查离散采样点。默认30秒未进入捕获球则判定失败。

结果发布到 `/simulation/impact/result`，消息类型为 `uav_usv_interfaces/InterceptResult`。结果区分 `SUCCESS`、`FAILURE` 和 `ABORTED`，失败原因包括 `TIMEOUT`、`STATE_LOST`、`OFFBOARD_LOST`、`CONSTRAINT_VIOLATION` 与 `INVALID_STATE`。

`/simulation/impact/hit` 只在真实成功时发布 `true`。CSV最终行保存真实捕获边界处的UAV和USV坐标，不得为了显示效果把两者坐标强制写成完全重合。真值只用于结果判定和评价，后续感知闭环不得读取该结果作为控制输入。

## 坐标约定

PX4本地坐标采用NED：x向北、y向东、z向下。相机输出必须先通过TF转换，禁止直接把相机光学坐标作为PX4设定值。
