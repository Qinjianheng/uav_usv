## 2. 项目目标与研究边界

项目目标是在ROS 2 Humble、PX4 SITL和Gazebo中研究四旋翼无人机对高速、非合作无人艇的感知、状态估计、轨迹预测、轨迹规划和截击控制。

当前是科研仿真系统，不是实船或实机可直接部署的软件。USV本身没有视觉标记；仿真阶段暂时用直径0.5米的红色小球验证相机、深度和坐标变换链路。现实非合作USV识别仍需目标检测或实例分割算法。

研究参考：

- Zhu等（2017）：四旋翼截击地面移动目标的同时轨迹生成；
- Gao等（2024）：动态场景中的自适应跟踪与栖落，重点参考目标预测、MINCO、观测方向和后续感知闭环；
- ZJU FAST Lab的MINCO/GCOPTER工作。

本机论文PDF：

- `/home/qin/snap/zotero-snap/common/Zotero/storage/5UDZKJNM/Zhu 等 - 2017 - A simultaneous trajectory generation method for quadcopter intercepting ground mobile vehicle-用于四旋翼拦.pdf`
- `/home/qin/snap/zotero-snap/common/Zotero/storage/ZVS7T6XB/Gao 等 - 2024 - Adaptive Tracking and Perching for Quadrotor in Dynamic Scenarios-无人机截击无人艇，车辆例子.pdf`

## 4. 当前系统数据链路

### 4.1 控制基准链路

```text
moving_target发布USV真值位置/速度
        ↓
CTRV预测（数据不足时退回CV）
        ↓
短时滚动截击 + 三段MINCO-T3
        ↓
PX4速度设定值 + 始终朝向目标的偏航
        ↓
Gazebo x500
```

控制器目前仍订阅：

- `/target/position`：USV仿真真值位置；
- `/target/velocity`：USV仿真真值速度。

这是为了先稳定验证规划和飞控。不要误称为“已经取消全局信息”。

### 4.2 相机与滤波影子链路

```text
前视RGB + 对齐32FC1深度
        ↓
红色目标掩膜 + 目标表面深度
        ↓
球半径补偿 + 相机内参
        ↓
相机安装外参 + UAV姿态/位置
        ↓
PX4本地NED目标位置
        ↓
六状态恒速度卡尔曼滤波
        ↓
位置/速度/未来位置，与真值并行比较
```

输出话题：

- `/perception/front/target_observation`：带有效性、置信度和协方差的相机观测；
- `/perception/front/target_position`：有效相机位置，供KF订阅；
- `/tracking/target_state`：KF位置、速度和6×6协方差；
- `/tracking/predicted_position`：配置时域后的KF预测位置。

这条链路不会控制UAV。相机丢失不会直接造成当前飞控失控，但会使相机/KF字段失效或留空。

## 6. 起飞、跟随和截击逻辑

### X：起飞并启动USV

- 地面阶段先预发送设定值并进入Offboard；
- 未收到X前保持不解锁，避免无人机自行翻落或消失；
- 收到X后解锁，USV同时出发；
- 起飞阶段Z轴爬升，同时平滑加入XY跟随；
- 为避免刚离地时大幅前倾，XY跟随在离地高度0.5至1.5米之间渐入；
- 起飞完成后进入FOLLOW MODE。

### 跟随

- 跟随USV已走航迹上弧长后方约5米的位置；
- 不是简单取当前航向切线后方点，因此8字转弯时参考点更连续；
- UAV偏航按 `atan2(target_y-uav_y, target_x-uav_x)` 指向目标。

### Y：截击

- 20 Hz滚动重规划；
- 目标预测优先使用CTRV，信息不足或速度过低时退回CV；
- 远距离阶段持续水平闭合，并按前视相机视场逐步下降；
- 进入1至2秒可达域后启用三段MINCO-T3；
- 每段为五次多项式；起终点满足位置、速度、加速度，段间保持一至四阶导数连续；
- 全轨迹检查水平/垂直速度、加速度和触海约束；
- USV预测弯曲轨迹用于内部引导点；不可行时逐级降低曲率权重；
- 无可行MINCO时回退直接追逐；
- 控制前视时间为0.15秒，避免每周期跳到轨迹远端。

当前实现是适合无障碍海面的轻量级MINCO，不是完整GCOPTER：没有安全走廊、障碍物ESDF和L-BFGS时空联合优化。

## 7. 相机配置与当前识别能力

### 前视RGB-D

- 安装位置（Gazebo FLU）：`(0.35, 0, -0.05) m`；
- 向下俯视：`12° / 0.20944 rad`；
- 分辨率：`640×480`；
- 水平FOV：`1.74 rad`，约99.7°；
- 更新率：`20 Hz`；
- RGB裁剪范围：`0.2–60 m`；
- 深度有效范围：`0.2–25 m`。

### 下视RGB-D

- 仍保留在模型中；
- 当前 `allow_down_fallback=false`，不会掩盖前视相机丢失；
- 本轮三维定位只使用前视相机。

### 红球和海面

- Gazebo目标是直径0.5米的红色小球；
- 球心相对USV真值参考点上移0.42米（NED中球心为 `target_z-0.42`）；
- RGB-D定位器用0.25米半径补偿目标表面深度，再把球心位置加0.42米恢复USV参考点；
- 海面为500×500米无碰撞视觉平面；
- UAV先接触海面仍由真值高度判定失败。

当前红色阈值识别仅用于仿真链路验证。后续现实无标记USV必须更换为检测/实例分割；坐标恢复、TargetObservation、KF和CSV评价接口可继续使用。

## 8. 成功与失败判据

成功判据：Y被接受后，UAV与USV真值相对轨迹连续进入半径 `0.25 m` 的三维捕获球。代码会检查相邻控制周期之间的线段穿越，不只检查离散采样点。

主要失败判据：

- `SEA_CONTACT`：UAV在进入捕获半径前达到海面，NED `z>=0`；
- `TIMEOUT`：Y后超过30秒仍未捕获；
- `STATE_LOST`：必需状态超时；
- `OFFBOARD_LOST`：Offboard模式丢失超过宽限时间；
- `CONSTRAINT_VIOLATION`：实际速度或加速度持续超过硬限制；
- `INVALID_STATE`：状态出现非有限数值。

命中时的相对速度目前只记录，不是成功阈值。当前判据评价“是否进入捕获半径”，还不能等同于现实中的安全栖落或有效物理截击。

## 9. CSV记录与预测误差

日志目录：`/home/qin/data/uav_usv/data/experiments/current`

CSV从X命令开始，包含 `takeoff`、`follow`、`intercept` 阶段。当前共104列，主要分组：

1. UAV真值位置、速度、加速度；
2. USV真值位置、速度；
3. 相机测量：`camera_x/y/z`、有效性、置信度、三维误差；
4. KF状态：`kf_x/y/z`、`kf_vx/vy/vz`、有效性、状态年龄、三维误差；
5. 未来预测：
   - `guidance_prediction_0p5/1p0/2p0_*`；
   - `kf_prediction_0p5/1p0/2p0_*`；
   - 每组包含预测 `x/y/z`、到期三维 `error` 和实际 `age`；
6. CTRV/CV模型、转向率、截击参考状态；
7. MINCO可行性、实际曲率权重和轨迹动力学峰值；
8. 指令、实测约束、最小距离与最终结果。

预测误差不是“当前预测对当前真值”。系统会保存历史预测，等0.5、1或2秒时域实际过去后，再与该时刻USV真值配对。因此每次日志最开始对应时域的字段为空是正常现象。相机不可见或深度无效时相机字段也会为空。

离线分析：

```bash
source /opt/ros/humble/setup.bash
source /home/qin/data/uav_usv/install/setup.bash
ros2 run uav_control usv_estimation_analysis \
  /home/qin/data/uav_usv/data/experiments/current/<日志文件.csv>
```

输出相机/KF有效率，并报告当前定位及0.5/1/2秒预测的样本数、平均误差、RMSE、中位数、P95和最大误差。

## 12. 已知局限与风险

1. 截击控制仍依赖 `/target/*` 真值，并未实现纯机载传感器闭环。
2. 红色分割只适合当前仿真小球，不适合现实非合作USV。
3. Gazebo深度是理想几何量，未模拟阳光红外干扰、海面反射、多径和深度空洞。
4. KF为恒速度六状态模型；USV执行8字转弯时，1至2秒预测可能产生明显系统误差。
5. 制导预测使用CTRV，但其输入仍是真值速度；与相机KF结果比较时必须说明输入条件不同。
6. MINCO平滑和约束可行不等于命中率必然提高，仍受预测误差、PX4跟踪滞后和可见性影响。
7. 当前MINCO没有障碍物规划和完整时空优化。
8. 当前成功判据是0.25米捕获半径，不包含接触姿态、冲击速度或栖落稳定性。
9. 前视深度最远25米；超距时可能RGB可见但无法输出三维ToF位置。
10. 相机时间同步目前使用到达时间近似，后续真实传感器必须使用消息时间戳和严格同步。

## 13. 下一步建议（按优先级）

### P0：先做新基线实验

1. 一键启动并完成至少10次相同初始条件试验；
2. 保存每次CSV和成功/失败结果；
3. 用 `usv_estimation_analysis` 汇总相机、KF和预测误差；
4. 统计MINCO启用率、追逐回退率、最小距离和成功率；
5. 检查相机位置是否存在固定偏差，尤其是Z轴0.42米和0.25米半径补偿。

在没有这些数据前，不要继续盲目调整MINCO或KF参数。

### P1：改善状态估计

1. 根据CSV标定相机位置协方差；
2. 将恒速度KF升级为CTRV-EKF或IMM（CV/CTRV）；
3. 使用真实图像时间戳做RGB、深度、UAV位姿同步；
4. 对短时丢失加入预测维持、协方差增长和重新关联逻辑；
5. 分别报告位置、速度和不同预测时域误差。

### P2：替换仿真红球识别

1. 在Gazebo中换成接近真实外观的USV模型；
2. 采集不同距离、视角、海面光照和遮挡数据；
3. 使用目标检测或实例分割输出目标框/掩膜；
4. 深度只在检测掩膜或视锥关联区域内取值；
5. 保留现有TargetObservation接口和真值评价链路。

### P3：传感器闭环切换

只有在相机/KF有效率和误差达到可接受水平后：

1. 为规划器增加 `use_estimated_target_state` 参数；
2. 控制输入从 `/target/*` 切换到 `/tracking/target_state`；
3. 状态失效时进入安全策略，而不是继续使用隐藏真值；
4. 真值继续只负责成功判定和误差评价；
5. 做真值控制与感知控制A/B试验。

### P4：进一步提高截击可靠性
